# gecko-ui

The shared look of the gecko apps, colours, type, buttons, scroll bars and the password dialog.\
It is part of [TumbleGecko](https://github.com/TumbleGecko/tumblegecko), where the apps that use it are shown.

## Install

An app copies these parts into its own `gecko-ui` folder.

```sh
./sync.sh /path/to/app/gecko-ui
```
